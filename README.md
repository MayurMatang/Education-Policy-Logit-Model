# Education-Policy-Logit-Model
This project builds a logit model that estimates the probability of a child enrolling in a private school versus a public school, based on their household's characteristics. The analysis uses microdata from the National Sample Survey Organization’s Education Consumption Survey, 2018 – one of India's largest household surveys – covering ~4,000 children in Gujarat.

This repository consists of R scripts of the logit model, a summary file interpreting the model and the executive summary of the policy paper for which the model was created.
